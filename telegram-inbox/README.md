# Telegram Inbox

هنا بتتحفظ التاسكات اللي بتيجي من جروب التيليجرام.

- `latest-task.txt` — آخر تاسك
- `tg-*.txt` أو `<mongoId>.txt` — أرشيف التاسكات
- عادل بيقرأ `latest-task.txt` ويستلم التاسك ويوزّع

التشغيل المحلي لاستقبال الرسايل + تحديثات مستمرة:
```bash
npm run telegram:poll
```

ملفات الحالة:
- `open-tasks.json` — التاسكات المفتوحة للمتابعة الدورية
- `/status` و `/done` من الجروب لإدارة المتابعة
