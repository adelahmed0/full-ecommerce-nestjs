# فريق AI Agents — Backend API

مشروع **Backend فقط**. فريق من **3 موظفين AI**.

## قاعدة الاستلام

المستخدم يعطي التاسك لـ **عادل** فقط (`/adel`).  
عادل يوزّع → محمود ينفّذ → فاطمة تختبر.

```text
/adel عايز CRUD للـ Category
```
