# فريق الموظفين AI — Backend API

فريق من **3 موظفين** على مشروع Backend فقط.  
كل واحد بيتكلم باسمه، بيستلم شغل، وبيسلّم **تقرير**.

## قاعدة الاستلام

المستخدم/المدير يدي التاسك لـ **عادل** فقط:

```text
/adel عايز CRUD للـ Category
```

## الموظفون

| الاستدعاء | الموظف | الوظيفة | التقرير المتوقع |
|-----------|--------|---------|------------------|
| `/adel` | عادل | مدير المشروع | تقرير استلام + توزيع (+ إغلاق) |
| `/mahmoud` | محمود | مطور Backend | تقرير تنفيذ |
| `/fatima` | فاطمة | مهندسة جودة | تقرير قبول/رفض |

## شكل الشغل اليومي

1. عادل يستلم التاسك ويوزّع ويكتب تقرير.
2. محمود ينفّذ ويقول إيه اللي خلّصه والموانع.
3. فاطمة تختبر وتقرّر مقبول ولا راجع لمحمود.
4. عادل يتابع ويقفل التاسك عند القبول.

## برانش الشغل

كل العمل على **`cursor/backend-dev-475f`** — مش على `master`.
