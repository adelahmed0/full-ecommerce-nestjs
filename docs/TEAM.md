# فريق تطوير مشروع Full E-Commerce (NestJS)

توثيق فريق السوفت وير المسؤول عن بناء وتشغيل منصة التجارة الإلكترونية الكاملة (مستخدمين، منتجات، سلة، طلبات، كوبونات، مراجعات، مدفوعات، والمزيد).

---

## الهيكل التنظيمي

```
                    عادل — مدير المشروع
                              │
              ┌───────────────┼───────────────┐
              │               │               │
         ياسر — محلل     نورة — مصممة    كريم — قائد تقني
         أعمال            واجهات UI/UX
                              │
         ┌────────────────────┼────────────────────┐
         │                    │                    │
    فريق الـ Backend     فريق الـ Frontend     فريق الجودة والتشغيل
```

---

## الإدارة والقيادة

| الاسم | الدور | المسؤوليات |
|------|--------|-------------|
| **عادل** | مدير المشروع (Project Manager) | التخطيط، الجدول الزمني، التواصل مع أصحاب المصلحة، إدارة المخاطر، متابعة التسليم، وتنسيق الفريق بالكامل |
| **كريم** | قائد تقني (Tech Lead) | القرارات المعمارية، مراجعة الكود، معايير NestJS/MongoDB، جودة الـ API، والإشراف الفني على المطورين |

---

## تحليل وتصميم المنتج

| الاسم | الدور | المسؤوليات |
|------|--------|-------------|
| **ياسر** | محلل أعمال (Business Analyst) | تحويل المتطلبات (Users, Products, Cart, Orders…) إلى مواصفات واضحة، وكتابة قصص المستخدم ومعايير القبول |
| **نورة** | مصممة واجهات (UI/UX Designer) | تصميم تجربة المستخدم للمتجر ولوحة الأدمن، التدفقات، والواجهات المتجاوبة |

---

## فريق الـ Backend (NestJS + MongoDB)

| الاسم | الدور | المسؤوليات |
|------|--------|-------------|
| **محمود** | مطور Backend أول | المصادقة والتخويل (JWT, Roles, Guards)، وحدة Users، والأمان |
| **سارة** | مطورة Backend | الكتالوج: Categories, SubCategories, Brands, Products, Suppliers |
| **أحمد** | مطور Backend | التجارة: Cart, Coupons, Orders, Tax، وتكامل الدفع (Stripe / Cash) |
| **هند** | مطورة Backend | Reviews, Request Product، الـ DTOs والـ Validation وـ Swagger |

---

## فريق الـ Frontend

| الاسم | الدور | المسؤوليات |
|------|--------|-------------|
| **منى** | مطورة Frontend أولى | واجهة المتجر: تصفح المنتجات، السلة، الدفع، والحساب |
| **عمر** | مطور Frontend | لوحة الأدمن: إدارة المستخدمين والمنتجات والطلبات والكوبونات |
| **ليلى** | مطورة Frontend | التكامل مع الـ API، الحالة المشتركة، وتحسين تجربة الموبايل |

---

## الجودة والتشغيل

| الاسم | الدور | المسؤوليات |
|------|--------|-------------|
| **فاطمة** | مهندسة جودة (QA) | اختبارات يدوية وآلية (Unit / E2E)، سيناريوهات الأدمن والمستخدم، وتقارير العيوب |
| **خالد** | مهندس DevOps | بيئات التطوير والإنتاج، CI/CD، النشر، المراقبة، وإدارة المتغيرات السرية |
| **ريم** | مسؤولة توثيق تقني | توثيق الـ API (Swagger)، دليل المطور، وملاحظات الإصدارات |

---

## توزيع المسؤوليات حسب وحدات المشروع

| الوحدة | المسؤول الأساسي | الداعم |
|--------|------------------|--------|
| Users & Auth | محمود | هند |
| Category / SubCategory / Brand | سارة | هند |
| Product / Suppliers | سارة | أحمد |
| Review / Request Product | هند | سارة |
| Cart / Coupon | أحمد | محمود |
| Order / Tax / Payment | أحمد | كريم |
| واجهة المتجر | منى | ليلى |
| لوحة الأدمن | عمر | منى |
| الاختبارات | فاطمة | الفريق التقني |
| النشر والبنية التحتية | خالد | كريم |

---

## قنوات التواصل والعمل

| البند | التفاصيل |
|------|----------|
| مدير المشروع | عادل — نقطة التواصل الرسمية للجدول والأولويات |
| الاجتماع اليومي | يومياً مع عادل وكريم ومتحدث من كل فريق |
| مراجعة الكود | كريم + مطور أول من نفس التخصص |
| قبول الميزة | ياسر (متطلبات) ← فاطمة (اختبار) ← عادل (إغلاق) |

---

## ملخص الفريق (14 عضو)

1. **عادل** — مدير المشروع  
2. **كريم** — قائد تقني  
3. **ياسر** — محلل أعمال  
4. **نورة** — مصممة UI/UX  
5. **محمود** — Backend أول  
6. **سارة** — Backend  
7. **أحمد** — Backend  
8. **هند** — Backend  
9. **منى** — Frontend أولى  
10. **عمر** — Frontend  
11. **ليلى** — Frontend  
12. **فاطمة** — QA  
13. **خالد** — DevOps  
14. **ريم** — توثيق تقني  

> الفريق مبني على نطاق مشروع **full-ecommerce-nestjs** والمتطلبات الموجودة في `docs/1-Requirements-ex.docx`.
