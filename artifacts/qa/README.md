# أدلة جودة فاطمة

هنا بتحفظ فاطمة صور وفيديوهات تجربة الموقع الحقيقي أثناء اختبار Frontend  
على **جميع أحجام الشاشات**.

أحجام إلزامية:
- Mobile: `375x667`, `390x844`
- Tablet: `768x1024`
- Desktop: `1280x800`, `1440x900`

أمثلة أسماء ملفات:
- `artifacts/qa/<task>-mobile-375.png`
- `artifacts/qa/<task>-tablet-768.png`
- `artifacts/qa/<task>-desktop-1280.png`
- `artifacts/qa/<task>-flow-mobile.mp4`

Backend يفضل توثيقه في `postman/` + تقرير تيليجرام.
